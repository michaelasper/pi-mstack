# Setup pstack

Run the native `/setup-pstack` command. It uses authenticated models and the current session scope. Review the complete role table before confirming. Cancellation leaves configuration unchanged.

In a headless session, inspect `/pstack doctor` and edit the versioned configuration only with explicit choices. Unavailable explicit selectors block their workflow. Never substitute a Cursor slug, fuzzy model match, or default budget. The native role-data section is independent of persistent mode. Native subagent preflight remains authoritative.
