## Grounding findings

Baseline check, typecheck and tests pass with optional live TLC and Git inventory tests skipped. The release investigator separately passed Git inventory and update tests. Native names are session-wide while mode and goal belong to the active branch. Fresh metadata-only sessions do not flush to disk before a conversation message. Explicit manual names and clears must win. Existing native test fixtures disable MCP and need real MCP execution coverage.

Version 0.3.0 is available at grounding time. Protected main requires a PR and CI. The previous trusted-publication workflow failed with npm E404, although 0.2.1 is now in the registry. Do not treat account access as proof that OIDC publication works. Release investigation's proposed zero-occurrence sweep is rejected. Remove executable and advertised typo support, but retain truthful historical notes and regression tests for the removed spelling.

## Initial contract candidates

The goal is explicit session intent, not an autonomous loop by default. Naming should preserve explicit user names. Glossary mappings describe local roles without claiming that different services have identical capabilities. Context providers must treat retrieved material as data rather than authority. Subagent tools and MCPs must be loaded through native supported configuration rather than merely named in prompts. These are design hypotheses pending grounding.
